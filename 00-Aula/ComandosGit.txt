Comando para poder iniciar o Git incializando repositório: git init

Comando para poder preparar as alterações para ir a próxima versão: git add 
Exite duas formas: git add "nome do arquivo ou pasta" ou git add . (esse segundo ele simpelsmente adiiconar todas as modificações para a próxima versão)

comando para poder fazer commit (salvar), no repositório, os arquivos preparados pelo git add: git commit -m "nome do commit"
